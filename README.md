## 🚀 安装方法

### Edge 浏览器
1. 打开 `edge://extensions/`
2. 开启右上角"开发人员模式"
3. 点击"加载解压缩的扩展"
4. 选择本项目文件夹

### Chrome 浏览器
1. 打开 `chrome://extensions/`
2. 开启右上角"开发者模式"
3. 点击"加载已解压的扩展程序"
4. 选择本项目文件夹

## 📖 使用说明

1. 点击浏览器工具栏中的扩展图标
2. 选择期权类型（买入看涨 Call / 买入看跌 Put）
3. 输入行权价、权利金、合约数、到期股价
4. 立即查看盈亏结果

## 📊 示例

| 参数 | 值 |
