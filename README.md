# 美股期权计算器 (US Stock Option Calculator)

专为中文美股散户设计的浏览器扩展，快速计算期权盈亏。

## ✨ 功能

- 📊 **实时计算**：输入行权价、权利金、到期股价，立即显示盈亏
- 💰 **成本明细**：自动计算投入成本、到期价值、盈亏比例
- ⚖️ **盈亏平衡**：自动计算盈亏平衡价
- 🛡️ **风险提示**：显示最大亏损（全部权利金）

## 🚀 安装

### Edge 浏览器
1. 打开 `edge://extensions/`
2. 开启"开发人员模式"
3. 点击"加载解压缩的扩展"
4. 选择本项目文件夹

### Chrome 浏览器
1. 打开 `chrome://extensions/`
2. 开启"开发者模式"
3. 点击"加载已解压的扩展程序"
4. 选择本项目文件夹

## 📖 使用说明

1. 点击浏览器工具栏中的扩展图标
2. 选择期权类型（买入看涨 Call / 买入看跌 Put）
3. 输入行权价、权利金、合约数、到期股价
4. 立即查看盈亏结果

## 📊 示例

| 参数 | 值 |
|------|-----|
| 期权类型 | 买入看涨 Call |
| 行权价 | $500 |
| 权利金 | $3.50 |
| 合约数 | 1 |
| 到期股价 | $520 |
| **结果** | **盈利 $1,650 (+471%)** |
